# Thư viện Đoàn phường Tam Thắng

Một website duy nhất: trang công khai và khu quản trị dùng chung Netlify + Supabase.

- Website: /
- Quản trị: /admin/ (Netlify chuyển tới admin.html)
- Logo: logo-doan.png ở thư mục gốc và assets/logo-doan.png
- Supabase: cấu hình trong supabase-config.js

Khi đưa lên GitHub, upload TOÀN BỘ nội dung trong thư mục này vào thư mục gốc repository, không upload file ZIP.
